# figures/

```
paper/          the manuscript's figures, named by the number they carry in paper_backbone.tex
fig_panel1..8/  raw notebook output, one directory per notebook in notebooks/panel/
legacy/         earlier explorations, kept for provenance, not referenced by either manuscript
```

**`paper/` is generated, not authored.** `py/organize_paper_figures.py` parses
`paper/paper_backbone.tex`, resolves which `fig_panelN_*/` file backs each figure number, and copies
it in under a name a reader can match to the manuscript. Re-run it after adding, removing or
renumbering a figure; `paper/README.md` carries the full mapping. Editing an image in `paper/` by hand
would be overwritten on the next run -- change the notebook that produces it instead.

`fig_panel1..8/` are written directly by the panel notebooks and are the reproducible artifacts: every
image there is regenerated by re-running its notebook. Names describe how a figure was made rather
than where it appears.

`legacy/` holds figures from earlier lines of work. `backbone_paper/` belongs to the separate
contact-conditioned backbone-generation manuscript (`paper/paper.tex`); `inverse_folding/` and
`iedb/` are single-system studies that preceded the fifty-structure panel; `denovo_md/` is RFdiffusion
and molecular-dynamics output. Nothing here is cited by a current manuscript. Scripts that wrote these
directories still point at the old top-level paths, so re-running one recreates its directory at the
top level rather than inside `legacy/`.
