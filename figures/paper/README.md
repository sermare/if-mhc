Every figure in `paper/paper_backbone.tex`, named by the number it carries in the
manuscript. **These are copies.** The originals are written by the panel notebooks into the
`figures/fig_panelN_*/` directories; this folder is regenerated by
`py/organize_paper_figures.py`. Editing an image here would be overwritten on the next run --
change the notebook that produces it, re-run that notebook, then re-run the script.
